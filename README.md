# Lead Dispatcher

Черновая реализация импорта лидов и просмотра очереди. Текущая версия **ничего не отправляет адресатам**.

## Что готово

- Разбор подписи к фотографии: `@username` или телефон; российские номера `8…` приводятся к `+7…`.
- Импорт пересланных в управляющего бота фотографий с сохранением фото на диск.
- Очередь в SQLite, защита от повторного импорта и просмотр от новых публикаций к старым.
- Три варианта первого сообщения и общий второй текст в `config.example.json`.
- CSV со случаями, где в подписи нет контакта или фотографии.
- Чтение фото из доступного аккаунту канала от новых сообщений к старым.
- Поиск по номеру через `contacts.resolvePhone`, без добавления номера в контакты.
- Управляющий бот отвечает оператору на `/start`, `/status`, `/preview`, `/unresolved` и принимает пересланные фото.

## Запуск без отправки

Нужен Python 3.10+. Секреты храните только в переменных окружения, не в репозитории.

```sh
export TELEGRAM_BOT_TOKEN='...'
python3 lead_dispatcher.py import-bot-updates
python3 lead_dispatcher.py preview
python3 lead_dispatcher.py export-unresolved data/unresolved.csv
```

`import-bot-updates` только читает ожидающие обновления Bot API и скачивает фотографии. Он не подтверждает обновления, поэтому повторный запуск видит те же записи, а база их пропускает. Если Telegram не показывает пересланные посты, можно загрузить JSON с полями `source_chat_id`, `source_message_id`, `caption`, `photo_path` через `import-json`.

Когда будет отдельная авторизованная сессия рабочего аккаунта, можно прочитать канал:

```sh
python3 -m pip install -r requirements.txt
export TELEGRAM_API_ID='...'
export TELEGRAM_API_HASH='...'
export TELEGRAM_SESSION_PATH='data/main_account'
python3 telegram_adapter.py --channel 'ссылка_или_ID_канала' --limit 100
```

`telegram_adapter.py` читает канал и умеет искать адресата по username или номеру. Он не отправляет сообщения. Результат поиска по номеру зависит от настроек приватности адресата; Telegram требует паузу не менее трёх секунд между такими запросами.

Управляющий бот запускается отдельно:

```sh
export TELEGRAM_BOT_TOKEN='...'
export TELEGRAM_ADMIN_CHAT_ID='...'
python3 bot_control.py
```

Только указанный оператор может получать ответы и пересылать новые посты в очередь. Бот отвечает в личном чате оператора и не пишет адресатам лидов.

## До подключения рабочего аккаунта

Для прохода по всей истории канала и личных сообщений нужен Telegram user account через MTProto. BotFather token служит только для управляющего бота: бот не может первым написать произвольному пользователю. Отправку и распознавание номера нужно тестировать на контактах, предоставленных владельцем. Ограничения приватности могут помешать найти аккаунт по номеру.

Перед запуском потребуется определить правила пропуска повторов и уже обработанных людей, окно отправки и отчёт о ненайденных адресатах. Все отправки должны быть выключены до отдельного разрешения владельца.
